# Siravit Saelee — Profile & Portfolio

Personal website of Siravit Saelee (EN/TH).

## Publish with GitHub Pages
1. Create a new repository (e.g. `siravit-website`) and upload **all files in this folder** — `index.html`, the `images/` folder, `.nojekyll` and this README.
2. Go to **Settings → Pages**, set *Source* to **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
3. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Structure
- `index.html` — the whole site (pages switch via `#home`, `#profile`, `#work`, `#cosplay` …)
- `images/` — all photos and certificates used on the site
