วิธีใช้เว็บนี้
รูปทุกรูปตอนนี้เป็นรูปตัวอย่าง (`assets/img/placeholder.svg`) ให้เอารูปจริงใส่ใน `assets/img/` แล้วแก้ `src="assets/img/placeholder.svg"` ในไฟล์ .html ให้ชี้ไปที่ไฟล์ใหม่ และใส่คำอธิบายรูปใน `alt=""`
ข้อความทั้งหมดเป็นข้อมูลตัวอย่างจากแบบร่าง ให้แก้เป็นข้อมูลจริงของคุณ
อีเมลและลิงก์โซเชียลใน footer เป็นค่าชั่วคราว (`your-email@example.com`, `#`) ต้องแก้ทุกหน้า
สี ตัวอักษร มุมโค้ง อยู่บนสุดของ `assets/css/style.css` (ส่วน `:root`) แก้ที่เดียวมีผลทุกหน้า
อัปโหลดทุกไฟล์ขึ้น repo `sunsky220.github.io` (ไฟล์ชื่อซ้ำจะถูกแทนที่) ไฟล์ `portfolio.html` เดิมไม่ถูกใช้แล้ว ลบได้
รูปใหญ่ 3 รูปที่ใส่ได้ (ถ้าไม่มีไฟล์ จะเห็นสีไล่เฉดแทน): `assets/img/hero.jpg` (หน้า Home), `assets/img/banner.jpg` (แถบบนของทุกหน้า), `assets/img/city.jpg` (แถบล่างของทุกหน้า) ตั้งชื่อตามนี้แล้ววางในโฟลเดอร์ `assets/img/` ได้เลย ไม่ต้องแก้โค้ด
ฟอนต์โหลดจาก Google Fonts ต้องต่ออินเทอร์เน็ต
